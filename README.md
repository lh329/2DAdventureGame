# 2D Adventure Game

一个 Unity 2D 横版冒险游戏，包含完整的关卡、敌人 AI、Boss 战、道具系统和场景特效。

## 运行环境

- Unity 2022.3 LTS 或更高版本
- Windows / macOS / Linux

## 如何运行

1. 克隆仓库
   ```bash
   git clone https://github.com/lh329/2DAdventureGame.git
   ```
2. 用 Unity Hub 打开项目文件夹
3. 在 Unity 编辑器中打开 `Assets/Scenes/Level1.unity` 或 `Level2.unity`
4. 点击 Play 按钮运行

## 控制方式

| 按键 | 功能 |
|------|------|
| A / D 或 ← / → | 左右移动 |
| Space | 跳跃 |
| 鼠标左键 | 攻击 |

## 核心功能

| 功能 | 说明 |
|------|------|
| 双关卡 | Level1 横版闯关 + Level2 Boss 战 |
| 敌人 AI | 巡逻敌人 + 飞行敌人，带追踪弹 |
| Boss 多阶段 | 半血狂暴（攻击加速 + 子弹 +3 + 全屏震撼演出） |
| Boss 死亡演出 | 闪烁膨胀 → 慢动作爆炸(0.3x) → 碎裂渐隐 → 胜利 |
| 道具掉落 | ❤️ 回血心 (30%) / ⭐ 无敌星 4秒 (20%) / 🛡 护盾 8秒挡1次 (20%) |
| 受伤无敌帧 | 被击中后 0.8 秒闪烁无敌，防止连击秒杀 |
| 关卡过渡 | 淡入淡出黑屏切换，不再硬切 |
| 敌人死亡粒子 | 击杀敌人时 8 个碎片飞散 + 重力下坠 + 渐隐 |
| Boss 血条 | 0.3 秒缓动过渡，不是瞬间掉血 |

## 小巧思

- 🧞 **Boss 魔毯**用 Mesh 顶点变形实现真实布料波浪感，不是简单上下浮动。波浪、起伏、微倾三重动画叠加
- 💢 **Boss 狂暴三阶段演出**：蓄力闪烁(0.6s) → 全屏红闪+大震+膨胀(1.0s) → 余震脉动(0.8s)，暂停攻击等演出结束再开打
- 💥 **Boss 死亡**先闪烁膨胀 1 秒，再进入慢动作(0.3x)爆炸闪光 + 碎裂渐隐 1.5 秒，最后 0.5 秒停顿才弹胜利面板，给足仪式感
- 🛡️ 护盾不用气泡包裹（定位难对不齐），改用角色蓝光变色 + 头顶盾牌图标浮动，视觉清晰又不穿模
- 💎 道具落地后用固定 Y 基准 + 正弦波浮动，不会漂移走
- 📉 血条平滑 0.3 秒缓动，比瞬间掉血更有打击感
- 🎬 场景切换黑幕用 DontDestroyOnLoad 跨场景存活，协程不中断
- 💠 敌人死亡粒子继承敌人自身颜色，碎片方向均匀 + 随机偏移，每只怪死法都略有不同
- ⏱️ Boss 死亡时魔毯同步隐藏，不会出现魔毯悬浮的违和感
- ✨ 受伤无敌帧用高频闪烁(10Hz)区分无敌星闪烁(8Hz)，玩家能一眼分辨状态

## 项目结构

```
Assets/
├── Scenes/              # 关卡场景
│   ├── Level1.unity     # 第一关：横版闯关
│   └── Level2.unity     # 第二关：Boss 战
├── Scripts/             # 引擎相关脚本
│   └── CarpetWave.cs    # 魔毯波浪动画（Mesh 顶点变形）
├── 脚本/                 # 游戏逻辑脚本
│   ├── Player.cs        # 玩家控制 + 道具效果 + 无敌帧
│   ├── Enemy.cs         # 巡逻敌人 AI + 死亡粒子
│   ├── FlyingEnemy.cs   # 飞行敌人 AI + 死亡粒子
│   ├── Boss.cs          # Boss 多阶段 + 狂暴演出 + 死亡演出 + 血条缓动
│   ├── Bullet.cs        # 子弹/追踪弹
│   ├── ItemDrop.cs      # 道具掉落与拾取
│   ├── DeathParticles.cs # 敌人死亡粒子碎片
│   ├── GameManager.cs   # 游戏流程管理
│   ├── CameraControl.cs # 相机控制
│   └── SceneLoadManager.cs # 关卡切换 + 淡入淡出
├── Sprites/             # 游戏素材
├── Prefabs/             # 预制体
└── Editor/              # 编辑器工具脚本
```
